# Secure Payment Website

A modern payment gateway user interface built with Next.js, React, TypeScript, and Tailwind CSS.

## Features

* Secure Payment Landing Page
* Visa & Mastercard Support
* Multiple Currency Selection
* Custom Transaction Amount Input
* Card Number Validation
* Expiry Date Input
* CVV Input
* Payment Success Page
* Payment Failed Page
* Responsive User Interface

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* React Icons

## Installation

1. Clone the repository

git clone https://github.com/Chathuni-Nimesha/payment-website.git

2. Navigate to the project folder

cd payment-website

3. Install dependencies

npm install

4. Run the development server

npm run dev

5. Open in browser

http://localhost:3000
